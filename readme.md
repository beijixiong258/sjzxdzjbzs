# 三角洲行动装甲兵小助手

这是一个面向《三角洲行动》全面战场玩家的本地网页工具，用于查看载具三维模型、命中部位、武器伤害和修理规则。项目目录名为 sjzxdzjbxzs。

## 主要功能

- **载具查看**：旋转、平移和缩放模型，切换观察视角，查看命中部位、反应装甲和碰撞体。
- **甲弹对抗**：选择目标载具、命中位置、入射角及武器，查看单次命中的伤害和计算过程。
- **修理规则**：查看修理来源、自愈延迟、修复速度和修复上限。

## 启动方法

双击根目录的 [start-windows.cmd](start-windows.cmd)，等待浏览器自动打开。关闭启动器窗口即可停止服务。启动器会尝试使用 8777 至 8790 之间的可用端口，无需构建或另外安装开发运行环境。

请通过启动器打开页面；直接双击网页文件可能无法加载数据和模型。

## 用记事本修改数据

所有游戏参数集中在 [docs/data.json](docs/data.json)。玩家修改这一份文件、保存并刷新页面即可生效，无需改代码或重新打包。

例如，要调整毒刺发射器的直击伤害：

1. 用记事本打开 docs 目录中的 data.json。
2. 按 Ctrl+F 搜索 `"名称": "毒刺发射器"`，找到“步兵武器”中的对应条目。
3. 在该条目的“伤害段”中找到“类型”为“直击”的一段，将它的 `"基础伤害": 550` 按需要改为其他数值，例如 600。爆炸段的基础伤害为 100，若未调整爆炸伤害就保持原值。
4. 使用 UTF-8 编码保存文件，再刷新浏览器页面。

上面的 600 只是操作示例，项目保留的原始直击数值仍为 550。同名载具武器还需核对“所属载具”，避免改到另一辆车的武器。

| 想调整的内容 | 在数据文件中修改的位置 |
| --- | --- |
| 武器的直击、爆炸或持续伤害 | 步兵武器／载具武器 → 对应条目 → 伤害段 → 基础伤害 |
| 某种装甲受到的伤害系数 | 对应伤害段 → 装甲系数 → 对应装甲名称 |
| 载具总耐久、护盾或承受倍率 | 载具 → 对应载具 → 总耐久／护盾／直击承受倍率／爆炸承受倍率 |
| 部位伤害倍率 | 载具 → 对应载具 → 命中部位 → 直击倍率／爆炸倍率 |
| 模拟器的入射角区间和倍率 | 入射角方案 → 计算设置所选的方案，默认使用“通用” |
| 独立部位耐久、损坏惩罚 | 载具 → 对应载具 → 独立部位 |
| 自愈延迟、修理速度与修复上限 | 修理规则 → 对应载具及修复来源 |

删除武器时，删除“步兵武器”或“载具武器”数组中对应的整个对象，并处理好相邻条目之间的逗号。保存并刷新后，它就会从选择列表中消失。已从当前功能中移除的旧道具记录不再收入这份数据文件。

基础伤害和装甲系数都是唯一维护的输入值，汇总伤害由程序实时计算。数值为 0 时按 0 计算；装甲系数为 0 表示该伤害段对这种装甲无效。

## 编辑时的注意事项

- 数字不要加引号，文字要保留英文双引号。不要使用中文逗号或在最后一项后面添加逗号。
- JSON 不支持注释；文件开头的“使用说明”用于放置说明文字。
- 不要随意修改载具编号、模型标识、资源路径或模型变换。三维模型和纹理继续保存在独立的资源文件中。
- 配置有格式错误、缺失的装甲系数或不合法数值时，页面会显示中文提示。修正并保存后，点击“重新加载”。

甲弹对抗使用“计算设置”选定的统一入射角方案；命中部位中关联的角度方案用于显示原始部位资料，沿用原项目的计算方式。最小伤害、爆炸半径、对步兵伤害等资料参数不参与当前单次满额命中计算，资料备注也不会改变计算结果。

## 项目结构

| 文件或目录 | 用途 |
| --- | --- |
| [docs/data.json](docs/data.json) | 唯一的数据文件，包含武器、载具、部位、修理、角度及模型关联数据 |
| [docs/data.js](docs/data.js) | 数据读取、中文字段适配及错误校验 |
| [docs/damage.js](docs/damage.js) | 伤害计算 |
| [docs/app.js](docs/app.js) | 三维显示及页面交互 |
| [docs/index.html](docs/index.html)、[docs/style.css](docs/style.css) | 页面结构与样式 |
| docs/models/、docs/vendor/ | 模型、纹理和本地三维显示库 |
| exports/ | 已整理的图片资料；图片内容不会随数据修改自动更新 |
| [start-windows.ps1](start-windows.ps1) | 本地网页服务 |
